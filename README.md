# HVNF Studios

**High-performance web development & digital modernization.**

We replace broken legacy sites for local, regional, and high-ticket service businesses with fast, bespoke web apps that capture calls, bookings, and trust.

## Live Site

🔗 [hvnf-studios.vercel.app](https://hvnf-studios.vercel.app) (or GitHub Pages after deployment)

## What We Do

- **Trades & Automotive:** Fast, mobile-first sites for detailers, mechanics, contractors
- **Medical & Dental:** Clean, trustworthy digital fronts for practices and clinics
- **Luxury Services:** Elevated web presence for high-ticket professional services

### Philosophy

**Show, don't tell.** We build working mobile-first previews from a business's public footprint, hand them to the decision-maker, and remove purchase friction.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion (Framer Motion) · GSAP · Three.js · Lenis · Vercel Edge
